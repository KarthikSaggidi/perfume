# Admin filters, CSV tools, and record actions

The dashboard uses the supplied green-and-gold reference with real store data. The sidebar and workspace have separate scroll containers. Reaching either end of the sidebar does not scroll the workspace. On mobile, navigation becomes a drawer with a close button, Escape support, and keyboard focus containment.

The dashboard filters reporting period, channel, fragrance family, product, order status, and delivery region. **Apply filters** updates the figures, chart, order summary, recent orders, and bestseller list together. **Reset** restores the last 30 days. The only current sales channel is the online store. Payment totals use paid orders and their placement dates; they are not a cash-collection ledger. Cancelled orders are excluded from bestseller quantities.

Each admin section has Import and Export icons in the top-right toolbar. Export uses that section's current search and filters. The workspace search shortcut is Cmd/Ctrl K. Products, inventory, orders, customers, campaigns, staff, activity, and settings have their own relevant filters.

## Import workflow

1. Select **Import**, choose the data resource, and download its CSV template.
2. Use UTF-8 CSV with the exact template column names. Import up to 100 data rows and 500 KB at once. Quoted commas, line breaks, and quotes are supported. Lists use `|` separators; booleans use `true` or `false`; campaign dates use ISO date strings.
3. Choose the file and select **Preview import**. The server validates the entire file without changing records. Expand **Review imported values** to inspect the uploaded cells.
4. Select **Import records** to commit the validated file. The preview is bound to that file, the administrator, and the current resource state. A concurrent edit or sale requires another preview. All rows commit together; an invalid row rolls back the batch.

Missing columns preserve existing values. Optional text cells can clear descriptions, notes, tags, and scheduling fields. Blank required catalog cells retain an existing value; new records still require valid mandatory fields. A blank `price100` removes its override. Spreadsheet-safe apostrophes added during export are removed on reimport, so international phone numbers and formula-prefixed text round-trip correctly.

| Resource | Import behavior |
| --- | --- |
| Products | Create/update by ID or SKU. Prices, stock, imagery, family, status, features, and fragrance notes are validated with the normal editor rules. |
| Inventory | Update existing products only. `stock` is the available bottle quantity shared by both sizes. `expectedStock` must match the exported quantity. |
| Campaigns & posters | Create/update by ID or campaign name. Linked products must exist. Store destinations must be internal paths. |
| Orders | Update existing orders by ID or number. Fulfilment transitions, payment records, tracking, and private notes are validated. Historical prices, quantities, customer identity, and totals cannot be rewritten. Create new orders through checkout. |
| Customers | Create/update CRM profiles by mobile number. Existing sign-in phone identities cannot change. Blocking revokes customer sessions. Marketing consent is not imported. |
| Store settings | Import editable `key,value` pairs. Currency and provider credentials are excluded. The exported settings file can be reimported. |
| Team & access | Owners can update existing staff names, roles, and activation. Self-demotion and removal of the last owner are prohibited. Passwords are excluded; create new staff through the dedicated form. |
| Activity | Export only: activity is generated by the server. Import opens the normal store-data selector; successful imports generate their own audit events. |

## Record actions

Use each record's three-dot menu to edit it and access its applicable actions. Product archival preserves historical orders. Campaign deletion requires confirmation. Customer blocking is reversible. Staff activation and roles remain owner-controlled. Orders retain their fulfilment and payment history; activity records are immutable.

## Storefront account menu

The account icon is the rightmost navigation control on desktop, tablet, and mobile. Signed-out customers see **Login / Sign up** and help. Signed-in customers see their profile, orders, wishlist, addresses, and **Logout**. Logout revokes the server session, clears the device's account wishlist copy, updates the navigation, and returns protected account/checkout screens to sign-in. Menus close with Escape or an outside click and support keyboard navigation.
